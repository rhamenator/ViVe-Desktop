Download the Setup-x64.exe for a normal per-user installation, or the portable ZIP.
Both include .NET 10; the app requests administrator access at launch.
The installer is currently unsigned. Check SHA256SUMS.txt. Do not disable antivirus
or add exclusions in response to a detection; report the exact detection instead.

Reboot notices are consolidated into one exit dialog after actual changes in that
session. Restart now reboots only when explicitly chosen; Later exits without
rebooting; Keep app open cancels the exit. Failed/partial writes still report errors.

Store-targeted and test-sideload MSIX files are separate GitHub Actions artifacts.
The Store identity is provisional and restricted capabilities still require approval.
