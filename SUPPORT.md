# Support

Use GitHub issues for reproducible bugs, compatibility observations and feature
requests. Include app version and the complete Windows build. Keep security
reports private as described in SECURITY.md.

This is an independent ViVe-based project, not a Microsoft or Albacore product.
Enabled configuration does not guarantee visible Windows behavior: builds,
dependencies and restart requirements can differ.

The app is free. Donations are entirely optional, do not buy features, access,
priority support or another benefit, and do not create a quid pro quo. Support is
best effort; no payment is required to use, modify or redistribute the GPL app.
